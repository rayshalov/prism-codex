# Prism

Prism — локальный менеджер аккаунтов Codex для macOS 13 и новее. Светлая тема использует полупрозрачные материалы и мягкую подсветку, тёмная — графитовые поверхности и латунные акценты. Можно выбрать любую тему или следовать настройке macOS. При открытии окно плавно выходит из размытия. Когда оформление меняется, содержимое слегка смещается вниз и размывается, а затем возвращается на место на неподвижном фоне. Если оформление совпадает с текущим или в macOS включено «Уменьшение движения», переход пропускается.

## Как пользоваться

1. Открой `dist/Prism.app`. В карточке текущего входа можно сохранить уже открытый аккаунт.
2. Нажми «Добавить» и закончи вход на странице OpenAI в браузере. Вход выполняет установленный Codex. Новый аккаунт добавится в список.
3. Нажми «Выбрать» и подтверди смену. Сначала заверши активные задачи в Codex и останови CLI в терминалах. Prism запрашивает обычное закрытие приложения, ждёт выхода, сохраняет свежую копию предыдущего входа, проверяет выбранный аккаунт через Codex и открывает приложение. Если проверка не прошла, восстанавливает прежний файл входа.

Для рабочего режима нужен установленный Codex Desktop или CLI и файловое хранилище входа ChatGPT. Prism использует `CODEX_HOME` из окружения или стандартную папку `~/.codex`. Поддерживаемый режим определяется через эффективную конфигурацию Codex. Настройки Codex и ограничения администратора Prism не редактирует.

Сохранённые сессии лежат в локальной Связке ключей macOS. Папка данных Prism хранит только метаданные списка. Для входа в браузере используется отдельная временная папка Codex с ограниченными правами. Файл активного входа хранится в стандартном для Codex формате и устанавливается с правами `0600`.

## Лимиты

В карточке текущего входа и в списке аккаунтов отображается остаток окон «5 ч» и «Неделя». У текущего входа время сброса показано сразу, у сохранённых аккаунтов оно доступно в подсказке при наведении. Лимиты загружаются при открытии Prism и по кнопке обновления. Если Codex не вернул одно из окон, Prism показывает «—». При сбое обновления ранее полученные данные остаются видны с отметкой об ошибке.

Prism запрашивает лимиты через отдельную временную сессию Codex и использует только краткоживущий токен доступа. Проверка не переключает аккаунт и не обновляет сохранённые токены. Если токен истёк, активируй этот аккаунт в Codex или войди в него заново и обнови лимиты.

## Сборка и проверка

```sh
./build-app.sh
./test-app.sh --live-runtime --keychain
open -na dist/Prism.app --args --preview
```

Сборка использует Apple Command Line Tools. Готовый пакет подписан локальной ad hoc подписью. Основные проверки используют синтетические сессии и временные каталоги. Флаг `--live-runtime` проверяет локальный протокол установленного Codex в отдельном профиле. Флаг `--keychain` создаёт, обновляет и удаляет тестовую запись в Связке ключей. Демонстрационный режим работает с примерами и не обращается к рабочему входу.

Порядок переключения изучен по [Codex Account Switcher](https://github.com/liuzhao1225/codex-account-switcher), MIT, Zhao Liu. Prism использует отдельные интерфейс и реализацию. Протокол локального подключения описан в [OpenAI Docs](https://learn.chatgpt.com/docs/app-server).
